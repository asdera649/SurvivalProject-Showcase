
**Мобильная многопользовательская онлайн игра** · Unity · C# · Mirror Networking

Также доступно на: [English](README.md)

Постоянный, соревновательный многопользовательский survival-проект на Unity. Игрок начинает с пустыми руками, добывает ресурсы, создает снаряжение, строит и защищает свой опорный пункт, сражается с другими игроками за ресурсы на общих серверах с серверной авторитетностью. Проект охватывает весь стек: игровой клиент, сетевую серверную симуляцию, лёгкий бэкенд-сервис и облачное сохранение.

## Основные игровые возможности

### Строительство и защита базыы
- Фундаменты, стены, полы, дверные проёмы, лестницы, треугольные детали, баррикады и служебные постройки - верстаки (3 уровня), печи, сундуки, спальные мешки и кровати, ремонтные верстаки.
- Три уровня материала построек: дерево → камень → металл, обновляются по отдельным деталям.
- **Графовая система устойчивости конструкций**: каждая деталь распространяет значение устойчивости от опорных деталей (фундаментов) через присоединённых соседей, с настраиваемым затуханием для каждого типа детали. Деталь нельзя разместить без достаточной устойчивости *или* прямой опоры на местность/фундамент, а разрушение опорной детали может вызвать цепное обрушение всего, что от неё зависело.
- **Территориальная система в духе Tool Cupboard**: авторизация конкретных игроков на строительство в пределах захваченного радиуса, периодическая оплата содержания ресурсами, чтобы постройки не «гнили», и временная блокировка рейда на всю базу при разрушении чего-либо неавторизованным игроком.

### Выживание и крафт
- Добыча дерева, камня, металлической и серной руды и других ресурсов из добываемых/собираемых объектов мира.
- Многоуровневые верстаки открывают доступ к рецептам для создания снаряжения.
- Прочность предмета снижается при использовании и восстанавливается на ремонтном верстаке.
- Еда и медицинские предметы восстанавливают здоровье; спальные мешки и кровати работают как персональные точки возрождения с отдельными таймерами перезарядки.
- При смерти инвентарь выпадает в контейнер на месте смерти, а на карте у игрока появляется метка, указывающая на место смерти.

### Бой
- Доступен ближний бой, огнестрельное оружие, метательное оружие и взрывчатка.
- Регистрация попаданий и урон проверяются на сервере, с переопределением урона по типу цели.
- Настраиваемая **помощь в прицеливании**, подсвечивающая/атакующая допустимые цели под прицелом;

### Мир и окружение
- Серверно-авторитетный цикл смены дня и ночи.
- Водные объёмы с физикой плавучести по отдельным поплавкам и механикой утопления.
- Система **видимости/«скрытия»** (`Hider`), которая приглушает стены, полы и внутренние объекты, когда они перекрывают камере обзор на собственную базу игрока.
- Миникарта и полноэкранная карта с пинч-зумом/панорамированием, метками, расставляемыми игроками, и автоматическими метками смерти.

### Мультиплеер и live-сервис
- **Браузер серверов**: список серверов в реальном времени, пинг, избранное и история недавних подключений.
- **Автосохранение** на выделенных серверах плюс **резервное копирование/восстановление в S3**.

## Техническая архитектура

### Поток загрузки приложения и сцен

Игра загружается через четыре сцены, каждая из которых владеет собственным `LifetimeScope` из [VContainer](https://github.com/hadashiA/VContainer) и точкой входа `IStartable` («flow»):

```
Bootstrap  →  Loading  →  Meta (главное меню)  →  Core (геймплей)
```

- **Bootstrap** - постоянный (persistent) корень; регистрирует сквозные сервисы (настройки, клиент бэкенда) и передаёт управление сцене Loading.
- **Loading** - проверяет совместимость версий клиента, прежде чем пускать игрока дальше.
- **Meta** - главное меню: браузер серверов и настройки.
- **Core** - игровая сцена. Общий асинхронный `LoadingService` последовательно дожидается загрузки каждого критичного для геймплея `ILoadUnit` (строительство, сохранения, авторизация, персистентность миникарты, резервное копирование на выделенном сервере, dev-инструменты...).

### Сеть (Mirror)

- Серверно-авторитетный геймплей с поддержкой headless-серверов.
- Собственные обработчики спавна `NetworkClient`
- **Собственный слой синхронизации предметов**: предметы инвентаря - это не `NetworkBehaviour`, поэтому сгенерированные Weaver'ом Mirror `[SyncVar]` / `[Command]` / `[ClientRpc]` нельзя навесить на них напрямую. Небольшой слой на рефлексии (`CustomSyncVar`, `CustomCommand`, `CustomClientRpc`) находит помеченные поля у любого `BaseItem` и прокидывает их синхронизацию/команды/RPC через владеющий предметом `Inventory` (настоящий `NetworkBehaviour`) - предметы получают полноценное сетевое состояние.

### Сохранения и персистентность

- Сохранение управляется атрибутами: любое поле/свойство, помеченное `[SaveHandler.Saved]` на любом компоненте, автоматически находится через рефлексию, сериализуется (QuickSave + Newtonsoft.Json) и восстанавливается, без ручного кода (де)сериализации под каждый тип сущности.
- Регистрация собственного обработчика спавна для каждого сохраняемого типа: загрузка сохранения восстанавливает объекты через обычную игровую логику и DI, а не через «слепой» `Instantiate`.
- Выделенные серверы автосохраняются с заданным интервалом и делают бэкап/восстановление файла сохранения в S3-совместимый бакет.

### Производительность и системы мира

- **Собственная система травы** (`GrassData`/`GrassGenerator`): расстановка запекается в редакторе в бинарный формат, разбивается на равномерную пространственную сетку и опрашивается во время выполнения поиском по чанкам.
- **LOD-система с двумя режимами** (`LodLayer`/`LayerSettings`): поддерживает и стандартные для Unity LOD по относительной высоте на экране, и удобный для левел-дизайнера режим «дистанция в метрах», автоматически пересчитываемый через угол обзора камеры.
- Универсальный пул объектов (`PoolService`) обслуживает VFX, обломки и снаряды.
- Запекаемый в редакторе рендерер карты цвета земли («ground color map») для генерации крупномасштабной текстуры цвета террейна.

### Взаимодействие, UI и ввод

- Система взаимодействия с объектами по близости (`InteractionSeeker`/`InteractionHandler`) со слоями поиска (лут против построек).
- Переиспользуемое, ориентированное на тач-ввод **радиальное меню** (зажал–потянул–отпустил) обслуживает действия оружия, переключение предметов и ремонт/улучшение/разрушение построек.
- Абстрагированный слой ввода (`BaseInput`/`BaseCameraInput`) с отдельными реализациями для мобильных устройств и ПК за одним интерфейсом.
- Локализованный UI (Unity Localization) с собственным хелпером умных строк, поддерживающим встроенную подстановку `{Key}` и типизированные переменные.

## Технологический стек

| Категория | Технология |
|---|---|
| Движок | Unity, Universal Render Pipeline (URP) |
| Сеть | [Mirror Networking](https://mirror-networking.com/) |
| Dependency Injection | [VContainer](https://github.com/hadashiA/VContainer) |
| Асинхронность | [UniTask](https://github.com/Cysharp/UniTask) |
| Аудио | FMOD for Unity |
| Контроллер персонажа | Kinematic Character Controller (KCC) |
| Система сохранений | QuickSave + Newtonsoft.Json |
| Резервное копирование | AWS SDK for .NET (Amazon S3) |
| Локализация | Unity Localization |
| UI | TextMeshPro, Unity UI Extensions |
| Прочее | Cinemachine, In-game Debug Console |

*Перечисленные сторонние пакеты/ассеты не включены в репозиторий.*

## Структура проекта

```
+-- Assets
|   +-- _Project
|       +-- Develop
|           +-- SP
|               +-- Runtime
|               |   +-- Bootstrap        # Точка входа приложения: запуск, загрузка настроек
|               |   +-- Loading          # Сцена загрузки: проверка версии → Meta
|               |   +-- Meta             # Главное меню: браузер серверов, настройки, запуск сети
|               |   +-- Core             # Корень игровой сцены
|               |   |   +-- Camera       # Ввод и камеры для ПК/мобильных
|               |   |   +-- Entities     # Игроки, постройки, ресурсы, контейнеры, добываемые узлы
|               |   |   +-- Environment  # Растительность и фоновое оформление мира
|               |   |   +-- Items        # Предметы инвентаря
|               |   |   +-- Movement     # Контроллер персонажа
|               |   |   +-- Objects      # Снаряды, взрывчатка, физические объекты
|               |   |   +-- Services     # Сохранения, авторизация, строительство, окружение, ресурсы...
|               |   |   +-- Systems      # Строительство, крафт, инвентарь, взаимодействие, LOD, трава...
|               |   |   +-- UI           # HUD, инвентарь, крафт, миникарта, радиальные меню, настройки
|               |   +-- Localization
|               |   +-- Utilities
|               +-- Editor               # Собственные инспекторы + инструменты левел-дизайна
```

## Примечания

- В этом репозитории только клиентский и серверный **игровой код** - арт, аудио и платные сторонние ассеты не включены.
- Опубликовано как проект для демонстрации.
